# Paradise Nursery Shopping Cart Application

Welcome to **Paradise Nursery**, an online shopping application for plant lovers! This React and Redux application allows users to browse various categories of plants, add them to a shopping cart, adjust quantities, and calculate total costs.

## Features
- Interactive Landing Page with "Get Started" button.
- Detailed "About Us" section explaining the company mission.
- Product Listing page categorized into Air Purifying, Aromatic, and Medicinal plants.
- Shopping Cart managed with Redux Toolkit (Add, Remove, Update Quantities).
- Dynamic calculation of item subtotals and overall total cost.
